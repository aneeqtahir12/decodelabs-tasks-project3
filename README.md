Data Science Project 3 - Decodelabs Tasks

This repository contains my Data Science Project 3 completed as part of the Decodelabs internship tasks.

Project Overview

This project focuses on data analysis and machine learning using Python. It includes data loading, data cleaning, exploratory data analysis, data visualization, and building a classification model using Logistic Regression to predict user behavior.

Tasks Completed
Task 1: Data Loading and Understanding
Loaded dataset using Pandas (read_csv)
Displayed dataset using head()
Checked dataset structure using info()
Analyzed dataset size using shape and size
Generated statistical summary using describe()
Task 2: Data Cleaning
Checked missing values using isnull().sum()
Identified duplicate records using duplicated()
Removed duplicate values using drop_duplicates()
Ensured dataset consistency for further analysis
Task 3: Exploratory Data Analysis
Analyzed target variable distribution using value_counts()
Performed group analysis using groupby()
Identified patterns between Age, Salary, and Purchased
Extracted meaningful insights from the dataset
Task 4: Data Visualization
Visualized data using Matplotlib and Seaborn
Created scatter plots to understand relationships between features
Used count plots to analyze class distribution
Interpreted visual patterns for better understanding
Task 5: Machine Learning Model
Separated features (X) and target variable (Y)
Split dataset into training and testing sets using train_test_split
Applied feature scaling using StandardScaler
Implemented Logistic Regression model
Trained model on training data
Predicted results on test data
Evaluated model using:
Accuracy Score
Confusion Matrix
Classification Report
